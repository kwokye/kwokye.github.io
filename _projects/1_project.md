**Organization**: Southwest Automation Research Institute  
**Role**: Principal Project Researcher (Jan 2022 – Dec 2024)

### Overview
This project addressed the challenge of target localization and continuous following for quadrupedal robots in complex, unknown, and GPS-denied environments.

### Key Contributions
- **Multi-Sensor Fusion**: Developed infrastructure-free and model-free target localization algorithms integrating Ultra-Wideband (UWB) ranging, IMU, and LiDAR point clouds using sequence matching.
- **Autonomous Navigation**: Implemented robust robot path planning and dynamic obstacle avoidance with the Dynamic Window Approach (DWA) framework and 3D pointcloud obstacle filtering.
- **Visibility-Aware Following**: Incorporated target visibility constraints to prevent tracking failure in cluttered surroundings.
